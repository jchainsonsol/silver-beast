# Silver Beast

A browser-based action platformer inspired by classic 16-bit arcade brawlers.

## Story

Battle through a cyberpunk Solana city, collect SOL power orbs, transform into increasingly powerful Silver Bull forms, and defeat the Void Tyrant.

## Forms

- Warrior
- Powered Warrior
- Silver Bull Beast
- Armored Bull

## Engine

- HTML5
- JavaScript
- CSS
